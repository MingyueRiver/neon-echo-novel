霓虹回响：零号协议 (Neon Echo: Protocol Zero)

🌌 简介 (Introduction)

这是一个基于纯 HTML/JS 的未来主义/赛博朋克风格交互式小说引擎。整个游戏封装在一个单文件中，无需服务器支持，即点即玩。

✨ 特性 (Features)

📺 沉浸式视觉: 内置 CRT 扫描线滤镜、屏幕辉光、动态 3D 网格背景及故障艺术 (Glitch) 字体效果。

🔊 程序化音效: 使用 Web Audio API 实时生成复古打字机声和 UI 交互音效，无需加载外部音频资源。

💾 完整游戏系统: 包含 HP (生命值)、SAN (理智值) 状态管理及动态物品栏 (Inventory) 系统。

🎲 多分支剧情: 玩家的选择会实时影响属性，并导向 4 个以上的不同结局（包括隐藏的真结局）。

📱 全平台适配: 响应式设计，完美适配桌面端和移动端浏览器。

🚀 如何运行 (How to Run)

下载本项目中的 index.html 文件。

直接使用现代浏览器（Chrome, Edge, Firefox, Safari）打开即可开始体验。

🌐 部署 (Deployment)

本项目非常适合通过 GitHub Pages 进行托管：

Fork 本仓库或将文件上传至您的仓库。

进入 Settings -> Pages。

在 Branch 选项中选择 main 并保存。

您的专属游戏链接将会自动生成。
